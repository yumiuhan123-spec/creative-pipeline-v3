# 流程状态文件

`3.1.0` 开始，标准项目模板中保留两个状态相关文件：

```text
00_project/project.config.json
00_project/workflow.state.json
```

## project.config.json

记录项目级配置，例如项目名称、输入目录、输出目录和浏览器提交设置。

它回答的是：

```text
这个项目是什么？
它的关键目录在哪里？
默认运行策略是什么？
```

## workflow.state.json

记录当前流程状态，例如已完成阶段、当前阶段、下一步允许执行什么。

它回答的是：

```text
这个项目现在走到哪里？
哪些步骤已经完成？
能不能从中间继续？
下一步应该停在哪里等人工确认？
```

## 后续计划

`3.2.0` 增加快速模式字段，用 `execution_mode` 和 `automation` 记录自动执行状态。真正的“从任意中间流程继续运行”仍建议作为后续独立功能实现。
