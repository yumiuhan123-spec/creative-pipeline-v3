# 快速模式

快速模式用于让 Codex 从读取素材一路执行到提交六个 ChatGPT 生图任务，中间不再反复向用户确认。

默认模式仍然是标准模式。只有在用户明确说“快速模式”，或项目配置中明确写入 `quick` 时，才允许进入快速模式。

## 标准模式

```text
P1 输入盘点
-> 等用户确认
-> P2 综合分析
-> P3 三套方案
-> 等用户选择
-> P4 提示词草稿
-> 等用户审核
-> P5 浏览器提交
```

标准模式适合高风险项目、新产品、资料不完整或需要人工控制方向的情况。

## 快速模式

```text
P1 输入盘点
-> P2 综合分析
-> P3 三套方案
-> Codex 自动选择或混合一套
-> P4 直接生成 final 提示词
-> 自动批准浏览器提交
-> P5 并发提交六个 ChatGPT 生图任务
```

快速模式适合用户已经接受 AI 自主决策、素材比较完整、目标明确、并且愿意先看结果再返工的情况。

## 快速模式必须记录什么

快速模式可以跳过人工确认，但不能跳过记录。

Codex 必须把自动决策写入项目文件：

- 为什么认为输入资料足够。
- 为什么选择某一套方案，或为什么混合方案。
- 哪些信息是保守假设。
- 哪些风险需要用户事后检查。
- 是否已经自动批准提示词和浏览器提交。

推荐记录位置：

```text
00_project/decisions.md
00_project/workflow.state.json
05_selected_scheme/selection_notes.md
06_prompts/prompt_overview.md
```

## 仍然不能跳过的情况

以下情况即使用户请求快速模式，也应该停止：

- 缺少能识别产品外观的关键图片。
- 缺少产品名称或品类说明。
- 卖点完全无法从资料中验证。
- ChatGPT 未登录。
- `batch_manifest.json` 或 `prompt_index.json` 不满足浏览器提交条件。
- 用户没有明确要求快速模式，项目配置也不是 `quick`。

## 启动语

```text
使用 $creative-pipeline-v3 以快速模式运行当前项目，从 P1 连续执行到 P5，自动选择方案、生成 final 提示词并提交六个 ChatGPT 生图任务。请把所有自动判断写入项目文件。
```
