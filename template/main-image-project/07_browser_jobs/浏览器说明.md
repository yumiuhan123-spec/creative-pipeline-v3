# 专用 Edge

正式流程会自动运行 `scripts/ensure_edge.ps1`。无需手动点击桌面快捷方式或批处理文件。

由于 Windows 默认执行策略可能禁止直接运行 `.ps1`，自动化必须使用：

```text
powershell.exe -NoProfile -ExecutionPolicy Bypass -File "07_browser_jobs/scripts/ensure_edge.ps1"
```

`启动专用Edge.cmd` 仅保留为人工测试入口，它调用同一个自动启动脚本。

- CDP 地址：`http://127.0.0.1:9222`
- 登录数据目录：`%LOCALAPPDATA%\CreativePipelineV3\EdgeProfile`
- 登录数据不放在项目目录中，因此复制项目不会丢失登录状态。
- 第一次由用户手工登录 ChatGPT。以后继续使用同一个启动文件。
- 浏览器分发阶段先探测 CDP：已有进程就复用，没有进程才自动启动。
- 浏览器分发程序只连接该进程，不应另开其他 Edge 用户目录。

如果 `9222` 已被另一个程序占用，应先关闭旧的工作流专用 Edge，再重新启动。
