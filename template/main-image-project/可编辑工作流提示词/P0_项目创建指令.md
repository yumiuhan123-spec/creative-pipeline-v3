# P0 项目创建指令

## 任务

从标准母版复制一个全新的项目，不覆盖现有项目，也不在母版之外临时拼装目录。

## 执行

运行：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File "00_project/scripts/copy_template.ps1" -Destination "<新项目绝对路径>" -ProjectName "<项目名称>"
```

## 规则

- 目标路径必须不存在。
- 目标路径不得位于标准母版内部。
- 复制完成后填写新项目的 `project_id`、`project_name` 和 `created_at`。
- 浏览器登录数据不复制，所有项目共享系统中的专用 Edge 登录配置。
- 不自动开始 P1。用户放入 `01_inputs` 后再运行。
