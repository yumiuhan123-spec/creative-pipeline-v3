# 项目级 Codex 指令

这里保存会直接影响执行结果的可编辑指令。

- 创建新项目时读取 `P0_项目创建指令.md`。
- P1 开始前必须完整读取 `P1_输入盘点指令.md`。
- P2 开始前必须完整读取 `P2_综合分析指令.md`。
- P3 开始前必须完整读取 `P3_方案生成指令.md`。
- P4 开始前必须完整读取 `P4_提示词生成指令.md`。
- P5 开始前必须完整读取 `P5_浏览器分发指令.md`。
- 项目复制后可以针对具体产品修改这些文件。
- Skill 只负责规定“必须读取”，具体执行标准以项目内文件为准。
- 修改指令后，在 `00_project/decisions.md` 中记录修改原因。

不要把产品事实写入这些通用指令。产品事实应放在 `01_inputs`、`03_analysis` 和 `05_selected_scheme`。
