# P5 浏览器并发分发指令

## 任务

自动启动或复用已登录的专用 Edge，在六个独立 ChatGPT 标签页中分别上传参考文件、填入六份最终提示词并并发提交图片生成任务。

Codex 不通过截图、坐标点击或手工复制执行常规分发。正常路径只运行项目内脚本并读取结构化日志。

## 执行前读取

1. `00_project/status.json`
2. `06_prompts/prompt_index.json`
3. `07_browser_jobs/batch_manifest.json`
4. `06_prompts/final/01.txt` 至 `06.txt`

## 强制前置条件

- `prompt_index.json` 状态为 `approved`。
- `status.json` 中 `prompts_approved` 和 `browser_submission_approved` 均为 `true`。
- 六个最终提示词不为空且不包含占位文本。
- `batch_manifest.json` 中正好存在六个任务。
- 每个任务引用的文件均位于项目目录内且真实存在。
- `batch_manifest.json` 中 `submit` 为 `true`。

任何条件不满足都必须停止，不得绕过。

## 执行

从项目根目录运行：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File "07_browser_jobs/scripts/run_distribution.ps1"
```

脚本负责：

1. 验证 CDP 和 ChatGPT 登录状态。
2. 创建或复用六个 ChatGPT 页面。
3. 按任务上传参考文件。
4. 分别填入提示词。
5. 在所有页面准备完成后并发提交。
6. 将标签页、会话地址、状态和错误写入日志。

## 停止与恢复

- 任一任务在提交前失败：不提交该任务，日志标记 `pre_submission_failure`。
- 任一任务已经提交：不得因等待时间过长而重复发送。
- P5 的终点是六个生成任务已经启动，不负责下载、筛选或修图。
