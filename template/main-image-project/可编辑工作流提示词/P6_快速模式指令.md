# P6 快速模式指令

快速模式不是新的业务阶段，而是 P1-P5 的连续执行策略。

默认仍然使用标准模式。只有用户明确说“快速模式”，或 `00_project/project.config.json` 中 `execution.mode` 为 `quick`，才允许执行本指令。

## 总目标

从读取素材开始，一路执行到六个 ChatGPT 生图任务提交完成，中间不暂停等待用户确认。

```text
P1 输入盘点
-> P2 综合分析
-> P3 三套方案
-> 自动选择或混合最终方案
-> P4 生成 draft 和 final 提示词
-> 自动批准浏览器提交
-> P5 并发提交六个 ChatGPT 生图任务
```

## 不得跳过的硬停止条件

即使是快速模式，以下情况也必须停止：

- 缺少能识别产品外观的关键图片。
- 缺少产品名称或品类说明。
- 卖点完全无法从资料中验证。
- 关键产品事实互相冲突，且无法做保守假设。
- final 提示词为空、仍是模板占位文本，或引用不存在的参考文件。
- ChatGPT 未登录。
- 浏览器分发脚本 preflight 失败。

## P1 自动确认规则

如果输入资料满足最低启动条件：

1. 正常生成 `02_inventory/input_manifest.json`。
2. 正常生成 `02_inventory/missing_information.md` 和 `source_notes.md`。
3. 将 `00_project/status.json` 中 `approvals.input_sufficient` 设为 `true`。
4. 将 `workflow.state.json` 中 `human_gates.input_confirmed` 设为 `true`。
5. 把自动通过的理由、缺口和保守假设写入 `00_project/decisions.md`。

## P3 自动选择规则

仍然必须先生成三套方案：

- `04_scheme_drafts/scheme_A.md`
- `04_scheme_drafts/scheme_B.md`
- `04_scheme_drafts/scheme_C.md`
- `04_scheme_drafts/scheme_comparison.md`

然后 Codex 自动选择一套，或混合出六张最终方案。

选择依据按优先级排序：

1. 产品事实和证据最稳。
2. 首图点击吸引力最强。
3. 六图叙事完整。
4. 制作难度可控。
5. 虚构风险最低。

输出：

- 将最终方案写入 `05_selected_scheme/selected_scheme.md`。
- 将自动选择理由写入 `05_selected_scheme/selection_notes.md`。
- 将 `status.json` 中 `approvals.scheme_selected` 设为 `true`。
- 将自动选择写入 `00_project/decisions.md` 和 `workflow.state.json`。

## P4 自动批准规则

1. 先写入 `06_prompts/draft/01.txt` 到 `06.txt`。
2. 自检通过后，同步写入 `06_prompts/final/01.txt` 到 `06.txt`。
3. 将 `06_prompts/prompt_index.json` 的状态设为 `approved`。
4. 将 `status.json` 中：
   - `approvals.prompts_approved` 设为 `true`
   - `approvals.browser_submission_approved` 设为 `true`
5. 将 `07_browser_jobs/batch_manifest.json` 中 `submit` 设为 `true`。
6. 在 `06_prompts/prompt_overview.md` 记录快速模式自动批准说明。

## P5 执行规则

快速模式不能绕过浏览器脚本校验。

进入 P5 前必须满足：

- `prompt_index.json` 状态为 `approved`。
- `status.json` 中 `prompts_approved` 和 `browser_submission_approved` 为 `true`。
- 六个 `final/*.txt` 均有效。
- `batch_manifest.json` 中 `submit` 为 `true`。

然后从项目根目录运行：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File "07_browser_jobs/scripts/run_distribution.ps1"
```

## 记录要求

快速模式可以跳过对话确认，但不能跳过记录。

每次自动决策都要写入：

- `00_project/decisions.md`
- `00_project/workflow.state.json`
- 对应阶段的正式输出文件

聊天回复中只需要报告最终提交状态、主要自动决策和需要用户事后检查的风险。
