# P1 输入盘点指令

## 任务

盘点 `01_inputs` 下的全部文件，理解每个文件可能承担的作用，建立输入清单并判断是否足以开始分析。只做盘点和缺口判断，不生成主图方案。

## 执行前读取

1. `00_project/project.yaml`
2. `00_project/status.json`
3. `01_inputs/放置说明.md`

## 执行方式

1. 运行 `07_browser_jobs/scripts/inventory.ps1` 生成基础文件清单。
2. 阅读可直接解析的文字资料。
3. 检查产品图片、竞品截图和评论截图的数量、类型与可读性；仅在理解内容确有必要时查看图片。
4. 将文件用途、来源和限制写入 `02_inventory/source_notes.md`。
5. 将缺失信息分成：
   - 必须补充，否则不能继续。
   - 可以使用保守假设继续，但必须明确记录。
   - 不影响当前任务。

## 最低启动条件

- 至少存在能够识别产品外观的产品图片。
- 至少存在产品名称或品类说明。
- 至少存在一个可验证的卖点、用途或目标买家信息。
- 能够区分哪些内容是产品事实，哪些只是竞品参考。

竞品图、评论和品牌资料可以缺失，但必须说明缺失会造成的分析限制。

## 输出

- `02_inventory/input_manifest.json`
- `02_inventory/missing_information.md`
- `02_inventory/source_notes.md`

如果资料不足，将状态设为 `waiting_for_inputs` 并停止。

如果资料足够，将状态设为 `waiting_for_input_approval`，向用户展示缺口摘要并等待确认。没有人工确认，不得进入 P2。
