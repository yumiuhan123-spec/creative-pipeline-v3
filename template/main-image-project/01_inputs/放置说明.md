# 输入资料放置说明

| 目录 | 放置内容 |
|---|---|
| `product_info` | 产品介绍、规格、材质、尺寸、卖点、限制、认证和不可宣传内容 |
| `product_views/three_view` | 一张同时展示产品正面、侧面和背面的三视图图片 |
| `product_views/details` | 产品结构、材质、包装和细节图片 |
| `competitor_main_images` | 竞品主图、详情页截图和视觉参考 |
| `reviews/raw` | 原始评论、截图和导出数据 |
| `reviews/structured` | 已清洗、分类或整理的评论数据 |
| `market_and_audience` | 市场、国家、买家角色和使用场景 |
| `brand_assets` | Logo、品牌色、字体、包装和品牌规范 |
| `other_references` | 无法归入以上类别的资料 |

工作流只把 `01_inputs` 作为正式输入源。不要将分析结果、方案或提示词放入这里。
