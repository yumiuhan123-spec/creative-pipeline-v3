# V3 主图类别定义

本文件是五类主图规则的唯一权威来源。不要再维护并行 JSON 版本。

用途：供后续主图方案生成 Skill 直接读取，替代每次重新读取 5 张参考图片。

这些定义描述的是主图的商业任务和编排逻辑，不要求复刻参考图片中的具体产品、配色、文案或版式。

## CAT-01 对比冲击型

### 核心任务

把“普通选择”和“目标产品”放在同一画面中进行直观对照，让买家快速理解升级价值、差异点或选择理由。

### 适用情况

- 产品拥有容易解释的结构、材质、功能或体验差异。
- 竞品或传统方案存在明确痛点。
- 需要教育市场，降低买家理解成本。

### 信息结构

1. 顶部使用强结论型标题，明确表达“差异、升级、为什么选择”。
2. 左右或上下分区展示两种方案。
3. 普通方案用弱化色彩、叉号或问题描述表现。
4. 目标产品用品牌主色、勾号和利益点表现。
5. 中间可使用 VS、箭头或升级路径强化对比。
6. 底部用一句购买结论收束。

### 视觉规则

- 目标产品必须比对照对象更清晰、更完整、更有质感。
- 对比维度控制在 3 至 5 项。
- 两侧信息结构尽量对称，方便快速扫描。
- 不应通过故意丑化、变形或虚构竞品缺陷制造优势。

### 方案生成指令

为当前产品设计一张“对比冲击型”主图构思。先从项目资料中识别最值得对比的传统方案、普通产品或旧使用方式，再选择 3 至 5 个有依据的差异维度。画面采用清晰的双栏或上下对比结构，目标产品为主要视觉焦点。标题必须让买家一眼理解升级价值。不得虚构竞品参数、认证、缺陷或未经证实的性能差距。

## CAT-02 高端品牌型

### 核心任务

通过极简构图、产品质感和克制的信息密度建立高端、专业、可信的品牌印象。

### 适用情况

- 产品外观、材质、工艺或设计感具有优势。
- 目标客户重视品牌调性、采购形象或高端场景。
- 不需要在第一张图中解释大量功能。

### 信息结构

1. 一句品牌定位或高层利益标题。
2. 一句简短副标题。
3. 单一产品英雄展示。
4. 右侧或下方放置 2 至 4 个简短特征。
5. 留出大量干净空间。

### 视觉规则

- 产品占据主要视觉中心，外观必须完整、准确。
- 使用柔和渐变、简洁展台、轻微光影或材质背景。
- 文字少而精，避免堆满参数和图标。
- 颜色、背景与产品定位一致，不盲目使用“科技蓝”。

### 方案生成指令

为当前产品设计一张“高端品牌型”主图构思。根据目标市场和产品气质选择合适的高端视觉语言，以单一产品英雄展示为中心，搭配一句定位标题、一句短副标题和不超过 4 个简洁特征。重点表现产品的真实轮廓、材质感、工艺感和品牌可信度。保持克制、留白和清晰层级，不使用密集参数，不虚构产品外观或工艺。

## CAT-03 场景代入型

### 核心任务

让目标买家立即看到产品在真实生活或工作中的使用方式，并把功能翻译为用户收益。

### 适用情况

- 使用场景是主要购买驱动力。
- 产品需要人物动作才能解释。
- 不同用户或时间节点对应不同价值。

### 信息结构

1. 主标题表达场景价值，而不是只写产品功能。
2. 中央或左侧展示核心人物使用场景。
3. 辅助区域展示 1 至 2 个补充场景。
4. 每个场景用短标签解释需求、动作和收益。
5. 产品在所有场景中保持一致、可识别。

### 视觉规则

- 人物身份、环境和动作必须符合目标客户。
- 产品不能被人物、手部或道具遮挡到无法识别。
- 场景应自然可信，避免人物僵硬地“展示产品”。
- 主场景占据多数视觉权重，辅助场景不能喧宾夺主。

### 方案生成指令

为当前产品设计一张“场景代入型”主图构思。根据用户画像、评论痛点和实际用途选择一个最强主场景，并补充 1 至 2 个次要场景。画面应展示目标用户正在自然使用产品，清楚表达使用动作、环境和直接收益。每个场景配简短信息标签。确保产品外观一致且清晰，不制造不符合现实的使用方式。

## CAT-04 爆款点击型

### 核心任务

在搜索列表、广告流或首屏中快速抢占注意力，让用户一眼看到核心卖点并产生点击兴趣。

### 适用情况

- 产品有一个强核心卖点。
- 流量环境竞争激烈，需要高识别度。
- 主图承担获客而非完整解释任务。

### 信息结构

1. 使用短、强、易读的大标题。
2. 产品以超大近景或英雄角度成为画面焦点。
3. 只呈现 2 至 4 个最关键卖点。
4. 使用图标、色块或视觉动线降低阅读成本。
5. 背景强化产品特征，但不能压过产品。

### 视觉规则

- 标题、产品、核心卖点形成明确的第一、第二、第三视觉焦点。
- 高对比不等于杂乱，应控制颜色和字体数量。
- 卖点必须来源于产品资料或已确认分析。
- 不使用虚假销量、夸张性能和绝对化承诺吸引点击。

### 方案生成指令

为当前产品设计一张“爆款点击型”主图构思。先从产品资料、竞品和评论中选出唯一最强核心卖点，再用短而有冲击力的标题表达。产品采用大比例英雄展示，搭配 2 至 4 个易扫读卖点图标或短句。建立清晰视觉动线，使用户先看到标题，再看到产品，再读取利益点。不得使用未经证明的数据或绝对化宣传。

## CAT-05 数字证明型

### 核心任务

使用真实、可追溯的数据、评价、检测、销量或服务指标降低采购疑虑，强化可信度。

### 适用情况

- 项目资料中存在真实评论、销量、评分、检测或履约数据。
- B2B 买家需要信任证据。
- 产品同质化较强，需要社会证明或质量证明。

### 信息结构

1. 顶部标题直接表达“数据证明、用户认可、检测结果”。
2. 产品作为中央视觉主体。
3. 选择 2 至 4 个最有价值的数字作为大号信息。
4. 使用图表、评分、评论摘录、测试项目或服务承诺辅助解释。
5. 每个数字标注来源、口径或待核实状态。

### 视觉规则

- 数字必须真实、可追溯，并保留来源。
- 不把不同统计口径拼成误导性结论。
- 评论摘录不得改变原意。
- 如果没有可靠数据，此类别应被标记为不可用，不得编造占位数字。

### 方案生成指令

为当前产品设计一张“数字证明型”主图构思。仅使用项目输入中可验证的数据、评论、评分、销量、测试或履约信息。选择 2 至 4 个最能降低买家疑虑的证据，以大数字、简洁图表、评价摘录或检测卡片呈现，产品保持为中央视觉主体。为每项证据保留来源说明。如果没有足够可靠的数据，明确判定该类别本轮不可用，不得生成虚构数字。

## 五类在六张主图方案中的使用原则

- 每套方案包含 6 张图片构思。
- 五类不是固定各用一张，而是候选类别库。
- Codex 根据产品阶段、资料完整度、买家痛点和平台目标进行组合。
- 同一类别可以在一套方案中出现两次，但必须承担不同任务。
- 数字证明型只有在存在可靠证据时才能使用。
- 六张图应形成完整叙事，而不是六张彼此独立的海报。

建议叙事顺序：

1. 第一张：最强获客主图，通常从高端品牌型、爆款点击型或场景代入型中选择。
2. 第二张：核心价值或对比解释。
3. 第三张：主要使用场景。
4. 第四张：产品细节、流程或第二场景。
5. 第五张：信任证明、评论洞察或采购保障。
6. 第六张：综合收束、定制能力或询盘引导。

## 通用禁用规则

- 不虚构产品结构、颜色、材质、附件和使用方式。
- 不虚构销量、评分、检测、认证、专利、客户或合作关系。
- 不使用未经证实的绝对化性能承诺。
- 不照搬参考图片中的品牌、产品、文案和数据。
- 不把类别定义理解为固定模板，应根据项目资料重新构思。
