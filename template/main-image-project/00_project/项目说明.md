# 主图方案生成标准项目

这是只读母版的复制件。开始新产品时，复制整个“主图方案生成”文件夹并重命名，不要直接在母版中运行项目。

## 固定流程

1. 将资料放入 `01_inputs` 对应目录。
2. Codex 读取 `可编辑工作流提示词/P1_输入盘点指令.md`，盘点资料并写入 `02_inventory`。
3. 人工确认输入后，Codex 读取 `可编辑工作流提示词/P2_综合分析指令.md`，完成分析并写入 `03_analysis`。
4. Codex 完整读取 `可编辑工作流提示词/P3_方案生成指令.md`，再生成三套候选方案，每套六张图，写入 `04_scheme_drafts`。
5. 人工选择、混搭或修改，将结果写入 `05_selected_scheme`。
6. Codex 完整读取 `可编辑工作流提示词/P4_提示词生成指令.md`，再生成六份自然语言提示词，先写入 `06_prompts/draft`。
7. 人工确认后，将定稿写入 `06_prompts/final/01.txt` 至 `06.txt`。
8. 浏览器阶段先自动运行 `07_browser_jobs/scripts/ensure_edge.ps1`；脚本复用已登录 Edge，未启动时自动启动。
9. Codex 读取 `可编辑工作流提示词/P5_浏览器分发指令.md`，浏览器分发程序读取 `06_prompts/final` 和 `07_browser_jobs/batch_manifest.json`。

## 人工审核入口

- 修改工作方法：`可编辑工作流提示词`
- 审核本次生成结果：`人工审核区`

P3、P4 完成后，应从 `人工审核区` 打开真实输出文件。该目录不保存副本。

## 重要规则

- `01_inputs` 中的原始资料不得覆盖或改写。
- 关键分析、选择和提示词必须保存到文件，不能只存在于聊天记录。
- 没有人工确认 `05_selected_scheme`，不得生成最终提示词。
- 没有人工确认最终提示词，不得提交浏览器任务。
- P1 至 P5 不得依赖 Skill 中写死的业务规则，必须以当前项目内的指令文件为准。
- 不得虚构产品性能、认证、测试数据、评论或服务承诺。
