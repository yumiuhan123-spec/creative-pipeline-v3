# 主图方案生成

## 运行前

1. 将产品资料放入 `01_inputs`。
2. 在 Codex 中将当前文件夹设为项目目录。
3. 输入：

```text
使用 $creative-pipeline-v3 运行当前项目。先执行 P1，检查输入资料并停下来等我确认。
```

## 两种不同的修改入口

### 修改工作方法

进入：

```text
可编辑工作流提示词/
```

这里修改的是 P1-P5 的执行规则。

### 修改本次生成结果

进入：

```text
人工审核区/
```

这里可以打开三套候选方案、最终方案、提示词草稿和最终提示词。

不要把这两类文件混淆。
